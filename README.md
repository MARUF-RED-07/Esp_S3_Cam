# Esp_S3_Cam
The intent of this board was to integrate 24pin camera modules with mmWave motion sensors to create a ceiling-mounted IoT node with an ESP32-S3 to serve as a security and monitoring node. The board also includes a 24V LED PWM dimming MOSFET with buck converter to enable powering the module from a 24V bus. Since this is a v0.1 prototype, additional headers are added including one for an I2S microphone. The ESP32-S3 MCU is used mainly to ensure minimal EMI core function of the processor but unfortunately this triggers 'standard' manufacturing rather than 'economic' manufacturing processes which is unfortunate because there are many 'basic parts' used in this BOM. Other notable features include a SHTC3 humidity and temperature sensor, and a LTC4311 I2C bus buffer for longer I2C runs to external sensors. The ICs are selected to work well with ESPhome and Home Assistant for home automation and code/firmware generation
